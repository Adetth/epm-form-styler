# EPM Form Styler

Applies colour themes to Oracle EPM form definitions. Built by **Adetth Raju**.

## Download

**[Download the latest version](https://github.com/Adetth/epm-form-styler/releases/latest)** - v1.1.0, 07 Oct 2026.

1. Download **EPM-Form-Styler-Setup-1.1.0.exe** from that page and run it.
2. If Windows says *"Windows protected your PC"*, click **More info** -> **Run anyway**. The app isn't signed with a paid certificate yet, so Windows doesn't recognise it; this is not a virus warning.
3. Setup installs for your user only (no admin rights needed) and adds Start menu and desktop shortcuts.

Needs Windows 10/11 and Google Chrome. Can't run installers? Use the zip on the same page: right-click > **Extract All**, then run `form_styler.exe` from the extracted folder.
